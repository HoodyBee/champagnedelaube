## 3 idées de stories

1. **« Devinez la page »** :
   - 3 stories avec une capture floutée d'une page du site (la carte des terroirs, une page cépage, Le Mag) et un sondage : « Quelle page est-ce ? ». La dernière story dévoile la réponse avec le sticker lien vers la page.
   - Visuel : captures du site.
2. **Les coulisses** :
   - une courte vidéo de vous qui présentez le site sur votre ordinateur (ou une capture d'écran animée), avec le texte « Le site est en ligne, venez le visiter ! », un sticker lien et la mention sanitaire.
   - Visuel : `julien-terrasse-ordinateur.jpg` ou une vidéo de l'écran.
3. **Le quiz terroir** :
   - « Combien de terroirs compte l'Aube ? » (réponses : 2, 4, 6). Réponse : 4, la Côte des Bar, Les Riceys, Montgueux et Villenauxe-la-Grande. Puis le sticker lien vers la page Les terroirs de l'Aube.
   - Visuel : la carte des terroirs (`carte-terroirs-aube-poster.jpg`).

**Rappel** : ajoutez la mention sanitaire sur chaque story où apparaît du champagne.
