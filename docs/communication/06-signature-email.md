# Signature e-mail Champagne de l'Aube

**Fichier de la signature** : `docs/communication/signature-email.html`.
- **Style** : un simple tableau aux couleurs du brand book (anthracite `#1E1E20`, bronze `#8A6420`, filet doré `#BF9140`, gris chaud `#5C5650`).
- **Polices** : de secours (Georgia et Arial), car Gmail et Outlook n'affichent pas les polices du site.
- **Logo** : chargé depuis le site (`https://champagnedelaube.fr/icon.png`). Il ne s'affichera donc qu'**après la mise en ligne** sur le domaine.

**Avant d'installer** :
- remplacez `[À COMPLÉTER]` par votre numéro de téléphone ;
- vérifiez le nom affiché (« Julien Mineo »).

## Aperçu

- **À gauche** : le logo rond (64 px).
- **Au milieu** : un filet doré vertical.
- **À droite** : votre nom en gras, « CHAMPAGNE DE L'AUBE » en petites capitales bronze, le téléphone, les liens vers le site et Instagram, et la mention sanitaire en petit.

## Installer dans Gmail (ordinateur)

1. Ouvrez `signature-email.html` dans votre navigateur : double-cliquez sur le fichier, ou glissez-le dans une fenêtre Chrome.
2. Sélectionnez toute la signature à la souris (pas avec Ctrl+A, qui prendrait toute la page), puis copiez-la (Ctrl+C).
3. Dans Gmail : ⚙️ **Paramètres** > **Voir tous les paramètres** > onglet **Général** > **Signature** > **Créer**.
4. Collez (Ctrl+V) dans la zone de signature. Le logo, les couleurs et les liens doivent apparaître.
5. Choisissez cette signature pour les nouveaux e-mails et les réponses, puis cliquez sur **Enregistrer les modifications** en bas de la page.

## Installer dans Outlook (Windows ou Mac, nouvelle version)

1. Ouvrez `signature-email.html` dans votre navigateur, sélectionnez la signature et copiez-la.
2. Dans Outlook : **Paramètres** (⚙️) > **Comptes** > **Signatures** > **Nouvelle signature**.
3. Donnez-lui un nom (« Champagne de l'Aube »), collez la signature, puis enregistrez.
4. Choisissez-la par défaut pour les nouveaux messages et les réponses.

**Si le logo n'apparaît pas dans Outlook**, c'est souvent parce qu'Outlook bloque les images distantes par défaut. Ce n'est visible que chez vous, et le destinataire le verra. Sinon, vous pouvez insérer le logo comme image dans l'éditeur de signature.

## Sur téléphone

Les applications Gmail et Outlook sur téléphone n'acceptent que des signatures en texte simple. Utilisez celle-ci :

```
Julien Mineo
Champagne de l'Aube
Tél. : [À COMPLÉTER]
champagnedelaube.fr · Instagram @champagnedelaube
L'abus d'alcool est dangereux pour la santé. À consommer avec modération.
```

## Conseils

- **Testez** : envoyez-vous un e-mail vers une adresse Gmail et une adresse Outlook pour vérifier le rendu.
- **Restez sobre** : n'ajoutez ni bannière ni grande image. Les signatures légères arrivent mieux et ne finissent pas en pièce jointe.
- **Mention sanitaire** : elle est conseillée dès que vos e-mails parlent de champagne.
