# Audit SEO : balises, partage et données structurées (21 novembre 2026)

Audit fait sur le site construit en mode « en ligne », sur les **88 adresses** du plan du site (français et anglais ; le néerlandais, l'italien et l'allemand sont masqués et non indexés).

## Ce qui a été corrigé

| Sujet | Avant | Après |
|---|---|---|
| Titres (50 à 60 caractères) | 45 pages hors limites | toutes entre 50 et 60 |
| Descriptions (140 à 160) | 38 pages hors limites, plusieurs coupées par « … » | toutes entre 140 et 160, aucune coupée |
| Indexation | `noindex` partout (site en construction) | `index, follow, max-image-preview:large` sur le site en ligne ; `noindex` sur les aperçus de PR, les langues masquées, les rubriques vides, Nos partenaires et la confirmation d'inscription |
| Open Graph (Facebook, WhatsApp, LinkedIn) | 26 pages sans image, aucune page avec le nom du site ni la langue | toutes : titre, description, image 1200 × 630 en JPEG, type (`website` ou `article` avec dates), langue (`fr_FR` / `en_GB`), langue alternative, nom du site, adresse |
| Twitter Cards | 26 pages sans carte | toutes en « grande image » |

| Icônes | favicon et icône Apple (déjà tirés de l'avatar) | + manifeste et icônes 192 / 512 px (dont une version « maskable ») pour l'écran d'accueil Android ; couleur du thème `#BF9140` (l'or du disque de l'avatar) |

**Remarque sur l'avatar** : il n'existe pas de fichier SVG de l'avatar dans le projet ni dans la Médiathèque ; les icônes viennent de `public/brand/logos/avatar.png` (3 000 px), redimensionné sans modification.

**Articles futurs** : titre = « Titre de l'article | Champagne de l'Aube » s'il tient en 60 caractères, sinon le titre seul ; description = le chapeau, coupé proprement à 160 caractères ; image de partage = la photo principale. Tout est modifiable dans le Studio (onglet « Référencement » de chaque article et de chaque page), avec un avertissement au-delà de 60 et 160 caractères.

## Pages 404

- Page 404 dans la charte, traduite (FR, EN), avec liens vers l'accueil, les terroirs, les dégustations privées et le Mag ; version bilingue pour les adresses qui ne correspondent à aucune page.
- Google reçoit un **vrai code 404** sur toutes les adresses inconnues (vérifié avec l'identité Googlebot). Pour un navigateur, Next.js peut répondre 200 avec une balise `noindex` (comportement normal de Next.js 16 quand la page est envoyée en continu) : sans effet sur le référencement.

## À vérifier après la mise en ligne

- Rendu des partages : [débogueur Facebook](https://developers.facebook.com/tools/debug/), [inspecteur LinkedIn](https://www.linkedin.com/post-inspector/), puis un envoi test sur WhatsApp. Je n'ai pas pu le faire : ces outils doivent lire le vrai site en ligne.
- Données structurées : [test des résultats enrichis de Google](https://search.google.com/test/rich-results) sur l'accueil, un article, une page terroir et Troyes.
- Les 5 photos de banques d'images font 960 à 1 024 px de large : en dessous des 1 200 px conseillés (Google Discover). Les versions haute définition sont listées dans `docs/photos-inventaire.md`.
- Les fonds en `background-image` relevés par l'audit sont uniquement les aperçus flous pendant le chargement : aucune image importante n'est un simple fond CSS.
