## Informations écartées

1. **Part des cépages rares dans le vignoble** : 0,3 % selon certaines sources (et l'ancien article), 0,04 % selon d'autres. Remplacé par « une toute petite place ».
2. **Pourcentages exacts** des trois grands cépages (38 / 31-32 / 30-31 %) : écarts entre sources ; seul l'ordre est donné.
3. **Surface d'arbane** (moins d'un hectare en 2006 selon une source, 1,28 ha chez un seul producteur selon une autre) : non citée.
4. **Chiffres de l'ancien article** (« plus de 10 000 cépages dans le monde », « 1 300 exploités », « une cinquantaine font 90 % ») : non vérifiés, retirés.
5. **Premières plantations certifiées de chardonnay rose en 2027** : une seule source, non citée.
